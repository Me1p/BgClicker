# SmartScreen и цифровая подпись

## Почему появляется предупреждение

Когда `BgClicker.exe` скачивают из интернета, Windows ставит на файл метку
Mark-of-the-Web. При запуске SmartScreen проверяет цифровую подпись и репутацию файла.
У неподписанного exe подписи нет, поэтому Windows показывает «Windows protected your PC»
(«Windows защитила ваш компьютер»).

Это **не означает**, что в файле вирус. Это означает «издатель неизвестен».

## Как убрать предупреждение полностью

Единственный надёжный способ — подписать exe сертификатом code signing, который доверяет
Microsoft. После подписи SmartScreen показывает имя издателя, а предупреждение исчезает
по мере накопления репутации (у EV-сертификатов — сразу).

Варианты для open-source проекта:

| Вариант | Стоимость | Комментарий |
|---|---|---|
| **SignPath.io** | бесплатно для OSS | Нужно подать заявку и подтвердить open-source проект |
| **Azure Trusted Signing** | недорого | Требует проверки организации/истории |
| **Certum Open Source** | ~25 €/год | Сертификат для OSS |
| **SSL.com / Sectigo OV** | от ~$100/год | Обычный OV-сертификат |
| **EV-сертификат** | дороже | Мгновенная репутация SmartScreen |

Бесплатно и без сертификата убрать предупреждение **нельзя** — это защита Windows,
а не настройка приложения.

## Подпись в этом репозитории

`build.ps1` умеет подписывать файл, если есть `.pfx`:

```powershell
.\build.ps1 -CertificatePath .\cert.pfx -CertificatePassword "пароль"
```

Для GitHub Actions добавьте секреты репозитория:

- `WINDOWS_CERT_PFX_BASE64` — содержимое `.pfx` в base64;
- `WINDOWS_CERT_PASSWORD` — пароль сертификата.

Workflow `Release` (`.github/workflows/release.yml`) декодирует сертификат, собирает и
подписывает exe, затем прикладывает файлы к GitHub Release.

Получить base64 из pfx:

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("cert.pfx")) | Set-Clipboard
```

## Что делать пользователю без подписи

1. Убедиться, что файл скачан из официального GitHub Release.
2. Проверить SHA-256:

   ```powershell
   Get-FileHash .\BgClicker.exe -Algorithm SHA256
   ```

   Хеш должен совпасть с `SHA256SUMS.txt` из релиза.
3. В окне SmartScreen нажать **«Подробнее»** → **«Выполнить в любом случае»**.

Файл, собранный локально (`build.ps1`), обычно не имеет метки интернета и не вызывает
SmartScreen.
